# LibraCore Frontend

Extracted from the supplied PDF source.

## Stack
- HTML5
- CSS3 with CSS variables and responsive media queries
- Vanilla JavaScript ES modules
- Inline SVG icons
- localStorage for theme/demo persistence

## Run
Open `index.html` in a browser. If your browser blocks ES modules from `file://`, serve the folder with a local static server, e.g. VS Code Live Server.

## Structure
- `index.html` — page shell, navigation, header, modal containers
- `css/style.css` — complete styling and responsive layout
- `js/app.js` — sample data, state, rendering, navigation, modals, search and demo interactions
